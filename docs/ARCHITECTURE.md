# 아키텍처

첫 MVP는 정적 테스트 페이지와 하나의 FastAPI 애플리케이션으로 시작합니다.

```text
Test Page
  ├─ 현재: 브라우저 안에서 2단계 모의 실행
  └─ 연결 후
       │ POST /api/v1/ad-copies/generate
       ▼
     FastAPI / ad_copy
       ├─ 광고 문구·CTA·해시태그
       └─ 이미지 생성용 프롬프트
              │
              ▼
          Image Model
```

광고 문구 한 건은 짧은 요청이므로 처음부터 Redis 큐나 별도 AI 워커를 두지 않습니다.
실제 측정 결과 HTTP 요청 시간 안에 안정적으로 끝나지 않을 때 비동기 처리를 도입합니다.

## 코드 경계

```text
apps/api/app/modules/ad_copy/
  router.py       HTTP 요청과 응답
  schemas.py      광고 문구 입력·출력 계약
  prompt.py       업종별 프롬프트와 버전
  service.py      모델 호출, 검증, 재시도
```

## 설계 원칙

- 기능이 하나인 동안 도메인 코드도 한곳에 둡니다.
- 모델 응답은 반드시 Pydantic 스키마로 검증합니다.
- 할인율, 가격, 운영시간처럼 사실이어야 하는 값은 입력받은 정보만 사용합니다.
- 모델명, 프롬프트 버전, 처리 시간과 오류를 기록합니다.
- 실제 사용자가 채택·수정한 문구를 저장할 때 개인정보와 보존 기간을 먼저 정합니다.
- 테스트 페이지는 이미지 결과를 모의로 표시하며 외부 모델을 호출하지 않습니다.
- 실제 이미지 생성은 광고 문구와 모델 간 전달 계약이 검증된 뒤 추가합니다.
