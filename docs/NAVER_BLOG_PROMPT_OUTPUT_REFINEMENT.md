# Naver Blog Prompt And Output Refinement

## 목적

Naver Blog 채널의 결과를 내부 분석 메모가 섞인 개발용 텍스트가 아니라, 사용자가 바로 복사해 게시할 수 있는 블로그 원고로 만든다.

이번 개선의 핵심은 다음과 같다.

- LLM이 작성하는 `publish_body`를 유일한 복붙 원고로 사용한다.
- 사진 추천, 사진 순서, 썸네일 이유는 내부 메타데이터로만 보관하고 원고에는 노출하지 않는다.
- LLM 응답이 실패하거나 형식 검증에 실패해도 fallback 원고가 같은 품질과 구조를 유지한다.
- 신메뉴, 세트메뉴 할인, 이벤트, 배달, 포장, 방문 유도 상황에 따라 제목, 도입, 안내 문장을 바꾼다.
- 이미지 위 제목은 긴 상품 소개가 아니라 `지역 + 업종 + 상호명`으로 짧게 제한한다.

## 최종 원고 구조

Naver Blog의 `publish_body`와 화면의 `네이버 블로그 복붙 원고`는 아래 순서를 사용한다.

```text
검색용 제목

인사말

상황에 맞는 도입 문단

[사진 1 - 대표 메뉴]

여러 메뉴를 합친 하나의 메뉴 소개 섹션

공간 소개

[사진 2 - 매장 내부 또는 전경]

감사 인사

📍 매장 안내
위치
추천 메뉴
운영 안내(사용자가 입력한 경우만)

해시태그
```

사진이 한 장이면 `사진 1`만 표시한다. 사진이 없으면 사진 삽입 표기 자체를 만들지 않는다.

## 최종 성공 예시

아래는 `신메뉴` 상황, `수제 딸기 티라미수`와 `피치에이드`, 운영 안내가 입력된 경우의 기준 결과다.

```text
연남동 카페 오후의 조각, 새롭게 준비한 수제 딸기 티라미수와 피치에이드를 소개합니다

안녕하세요.
오후의 조각입니다.

오늘은 오후의 조각에서 새롭게 준비한 수제 딸기 티라미수와 피치에이드를 소개해 드립니다.

[사진 1 - 수제 딸기 티라미수와 피치에이드]

수제 딸기 티라미수와 피치에이드를 소개합니다

수제 딸기 티라미수와 피치에이드는 오후의 조각에서 준비한 메뉴입니다. 가격은 수제 딸기 티라미수 6,500원, 피치에이드 5,000원입니다. 방문하신 날의 여유로운 시간과 함께 자연스럽게 즐겨 보세요.

편안하게 머물다 가실 수 있는 공간

[사진 2 - 매장 내부 또는 전경]

오후의 조각은 편안하게 머물며 메뉴를 즐길 수 있는 공간입니다. 매일 아침 직접 만드는 디저트 새로운 메뉴가 궁금하셨다면 매장에서 직접 만나보세요.

감사합니다.

📍 매장 안내
위치 : 서울 마포구 연남동
추천 메뉴 : 수제 딸기 티라미수 6,500원, 피치에이드 5,000원
운영 안내 : 평일 오전 11시부터 오후 2시까지 런치 세트 운영

#수제딸기티라미수 #피치에이드 #cafe
```

## 실패했던 출력과 원인

이전 결과에는 아래와 같은 내부 문구가 그대로 노출됐다.

```text
[대표사진 추천 - 수제 딸기 티라미수]
정보형 문체로 오후의 조각의 분위기를 자연스럽게 소개합니다.
[추천 사진 순서 - 피치에이드]
[사진 순서 추천 이유 - 매장 내부 또는 전경]
강조 포인트: 맛, 분위기
```

또한 첫 번째 상품과 두 번째 상품이 거의 같은 문장으로 각각 출력됐고, 가격 문자열 전체가 두 메뉴에 반복되어 다음과 같은 문제가 발생했다.

```text
수제 딸기 티라미수 가격은 6,500원, 피치에이드 5,000원입니다.
피치에이드 가격은 수제 딸기 티라미수 6,500원, 5,000원입니다.
```

원인은 세 가지 경로가 서로 다른 형식을 만들었기 때문이다.

1. LLM 프롬프트가 독자용 본문과 사진 분석 메타데이터를 함께 요구했다.
2. LLM 출력 검증 실패 시 fallback이 `정보형 문체로 소개합니다` 같은 작성 지시문을 본문으로 조립했다.
3. 프런트엔드가 `thumbnail_reason`, `photo_order`, `blog_sections`를 다시 조립하면서 내부 정보를 복붙 원고에 추가했다.

## 상황별 작성 규칙

| 선택 상황 | 제목/도입의 초점 | 안내 문장 |
| --- | --- | --- |
| 신메뉴 | 새롭게 준비한 메뉴와 첫 소개 | 매장에서 새 메뉴를 만나보도록 유도 |
| 세트메뉴 할인 | 할인 대상 세트와 적용 안내 | 입력되지 않은 할인율, 가격, 기간은 만들지 않음 |
| 이벤트 | 이벤트 소식과 참여 맥락 | 입력된 참여 방법과 기간만 사용 |
| 배달 | 집이나 사무실에서 즐기는 주문 맥락 | 배달 주문 확인 유도 |
| 포장 | 이동 중 또는 선물용 포장 편의 | 포장 주문 유도 |
| 방문유도 | 매장 공간, 위치, 머무는 경험 | 매장 방문 유도 |

## 운영 안내 규칙

`운영 안내` 입력값은 Naver Blog의 `📍 매장 안내`에만 사용한다.

```text
운영 안내 입력값 있음  -> 운영 안내 : 입력값
운영 안내 입력값 없음  -> 운영 안내 줄을 만들지 않음
```

운영 시간이나 런치 세트 정보가 `강조할 특징`에만 들어 있고 `운영 안내` 입력값이 비어 있으면, fallback의 매장 안내에는 운영 시간을 자동으로 넣지 않는다.

## 검증 방법

다음 항목을 확인한다.

1. Naver 채널에서 `대표사진 추천`, `추천 사진 순서`, `사진 순서 추천 이유`, `type=`이 복붙 원고에 나타나지 않는지 확인한다.
2. 여러 메뉴가 있을 때 메뉴 소개가 같은 문장으로 반복되지 않고 한 섹션에 통합되는지 확인한다.
3. 메뉴별 가격이 다른 상품 가격과 섞이지 않는지 확인한다.
4. 운영 안내 입력값이 있을 때만 매장 안내에 한 줄로 나타나는지 확인한다.
5. 매장 내부 또는 전경 사진이 `사진 2`로 표시되는지 확인한다.
6. 이미지 제목이 지역, 업종, 상호명 수준으로 짧게 표시되는지 확인한다.

API의 `prompt.py`, `output_validator.py`, `schemas.py`를 변경했으므로 테스트 전 API 서버를 재시작해야 한다. `app.js`, `index.html`, `styles.css` 변경은 브라우저 강력 새로고침으로 반영한다.
