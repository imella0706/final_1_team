# 탑뷰 접시 합성 안전 기준

탑뷰 음식 사진은 접시 외곽이 조금만 잘려도 합성 이미지가 부자연스러워진다. 이 파이프라인은 접시와 음식의 불투명 외곽을 기준으로 크기를 계산하고, 투명 알파 영역까지 포함한 안전 여백을 함께 이동한다.

## 전경 배치

- `models.foreground_placement.top_width_ratio`의 기본값은 `0.40`이다. 탑뷰 접시의 실제 외곽 너비가 결과 캔버스 너비의 약 40%가 되므로, 큰 원형 테이블 중앙에 자연스럽게 놓인다.
- `safe_padding_px: 28`은 알파 외곽 주변의 투명 여백을 보존한다. 축소 과정에서 접시 테두리, 얇은 무늬, feather 경계가 잘리는 일을 막는다.
- `canvas_margin_px: 42`는 배치된 전경이 결과 캔버스 경계에 닿지 않도록 한다.
- 실행 보고서의 `step_9_foreground_placement`에는 실제 외곽 비율(`width_ratio`), 안전 여백, 위치가 기록된다.

## 마스크 안정화

SAM 마스크의 작은 장식·굴곡이 사라지지 않도록 닫힘 커널은 9px, 최소 연결 요소 면적은 64px로 사용한다. 내부 구멍은 계속 채우므로 접시 내부로 생성 배경이 비치는 현상은 막는다. 현재는 BiRefNet을 사용하지 않고 안정화된 SAM 마스크를 합성 알파의 기준으로 사용한다.

## 음식·접시 레이어 분리

접시는 `plate_mask` 단계에서 구조 마스크의 가장 큰 윤곽을 별도 레이어로 만들고, 원형·타원형 접시로 충분히 일치할 때만 윤곽을 보완한다. 음식 마스크와 접시 마스크를 합친 뒤 안정화된 SAM 알파를 만들므로, 생성 배경이 접시의 끊긴 테두리나 내부 결손으로 비치지 않는다. 이 보완은 알파만 확장하고 원본 RGB 픽셀을 그대로 사용하므로 접시를 새로 생성하거나 디자인을 바꾸지 않는다.

실행 보고서와 디버그 산출물에는 `food_sam_mask`, `plate_mask`, `sam_stabilized_mask`가 저장된다. `step_2_sam2_food_container.stabilization.plate`의 `used_ellipse_completion`이 `true`이면 접시 외곽 보완이 적용된 경우다.

## 배경 후보 판정

음식 특화 YOLO는 원형 테이블 테두리나 강한 나뭇결을 음식으로 잘못 탐지할 수 있다. 따라서 이 탐지는 보고서용 경고로 유지하고, 후보 폐기 여부는 COCO 감사 탐지기가 **실제 전경이 놓일 중앙 안전영역**에서 음식·접시·컵·식기를 찾았는지로 결정한다. 탁자 가장자리의 장식이나 오탐만으로 좋은 빈 테이블 후보를 버리지 않는다.

탑뷰 원형 테이블은 테두리 때문에 전역 수평 경계가 강하게 검출될 수 있으므로, 후보 시점 검증은 전체 이미지의 선이 아니라 중앙 배치면의 비어 있는 정도를 사용한다.
