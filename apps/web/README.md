# 광고 생성 테스트 페이지

소상공인 입력부터 광고 문구와 이미지 결과까지 두 모델의 처리 과정을 확인하는
정적 테스트 페이지입니다. 광고 문구는 API를 통해 선택한 실제 LLM을 호출하고,
광고 이미지는 아직 CSS 모의 결과를 생성합니다.

## 확인할 수 있는 것

- 업종, 상황, 타겟, 톤, 상호명, 상품, 금칙어 입력
- Qwen, Llama, Mistral, Gemma, Phi, SOLAR 중 광고 문구 모델 선택
- 광고 문구 모델의 문구·CTA·해시태그 결과
- 광고 문구 모델이 이미지 모델에 넘기는 영문 프롬프트
- 두 모델 사이에 전달되는 전체 JSON
- 실제 이미지 모델 자리에 표시되는 CSS 기반 모의 광고 시안

## 실행

먼저 `apps/api`에서 API를 `http://localhost:8000`으로 실행합니다. 그다음 별도
터미널에서 테스트 페이지를 실행합니다.

`index.html`을 직접 열거나 이 폴더에서 정적 서버를 실행합니다.

```bash
cd apps/web
python -m http.server 5500
```

브라우저에서 `http://localhost:5500`으로 접속합니다.

## 파일

```text
index.html    화면 구조와 입력·결과 영역
styles.css    반응형 레이아웃과 모의 광고 이미지
app.js        모의 2단계 파이프라인과 결과 생성
```

API 주소를 바꿀 때는 `app.js` 상단의 `API_BASE_URL`을 수정합니다. 이미지 모델을
연결하기 전까지 이미지 영역은 `MOCK`으로 표시됩니다.
